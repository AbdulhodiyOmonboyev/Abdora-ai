# Contributor Covenant Code of Conduct

## Our Commitment

Abdora AI community ushbu Code of Conduct ga o'z xohishidan munosabat qilish uchun  o'zini majbur qiladi. Biz inclusive, hurmatli va xavfsiz muhitni saqlab qolishga  tayinlanmiz.

Bu Code of Conduct ni qabul qilish:
- Yangi contributors uchun ijobiy va supportiv muhit
- Bularni aniq qoidalar va ularni ijro etish
- Barcha ishtirokchilarga hizmat qilish

## Talabalar

Community a'zolari quyidagi xatti-harakatlarni namoyish etishlari kerak:

### ✅ Musbat Xatti-Harakatlari

- **Inclusive Language**: Hamma tillab, til va jamoat joylari
- **Respectful Debate**: Turli nuqtai nazarlar to'g'risini hali etish
- **Focus on Content**: Boshqa nuqtai nazarlarni raqibqa emas, kontentga qaratish
- **Show Empathy**: Boshqa community a'zolari bilan empathy qilish
- **Gratitude**: Topshiriqlar va feedbackga rahmat qilish
- **Accountability**: Xatolarni tan olish va o'rganish

### ❌ Qo'pol Xatti-Harakatlari

Community a'zolari quyidagini qilmasliklari kerak:

1. **Harassment**
   - Tahdid va qo'pollik
   - Shaxsiy hujumlar
   - Ehtiyojga qarshi qilish

2. **Discrimination**
   - Jins, jinsi, yoshiga ko'ra
   - Oila xolati bo'yicha
   - Shaxs, nlon yoki identifikator bo'yicha

3. **Sexual Harassment**
   - Istalmagan jinsiy diqqat
   - Jinsiy tahdid
   - Jinsiy kontentni majburiy qilish

4. **Violence & Threats**
   - Shiddatga alaika
   - Tahdidlar
   - Jisomoniy zarar

5. **Doxxing & Privacy Invasion**
   - Shaxsiy ma'lumotlarni e'lon qilish
   - Privacy ni buzish

6. **Trolling & Spam**
   - Intentional provocation
   - Uzun, qayta-qayta xabarlar
   - Off-topic spam

## 📢 Violation Reporting

### Xatti-Harakat Muammo Bo'lsa

Agar siz Code of Conduct ni buzilishini ko'rsang:

1. **Direct Message** (Shaxsiy)
   - projectLeadiga direct yozing
   - Privacy saqlanadi

2. **Email Report**
   - conduct@abdora.uz ga yozing
   - Anonimlik yo'naltirish mavjud

3. **GitHub Report**
   - Xususiy issue yarating
   - Details va evidence bilan

### Report Ichiga Nima Kiritish Kerak

```

Agar xohsangiz, qanday hal qilishni taklif qilish:
[Taklif]
```

## 🔍 Investigation Process

1. **Qabul Qilish**
   - Report qabul qilish tasdiqlanadi
   - Privacy saqlanadi

2. **Tekshirish**
   - Barcha tomonlar eshitiladi
   - Fakt yig'iladi

3. **Qaror**
   - 7 kundan iborat muddatda qaror chiqariladi
   - Guvohlar bilan informaciya almashiladi

4. **Tanbeh**
   - Warning yoki Suspension
   - Qo'shib yuborilgan, agar kerak bo'lsa

---

## 🛡️ Corrective Action

### First Violation
- **Written Warning** - Davoriysiz
- **Temporary Suspension** - 1-3 kun
- Community uchun apology talab qilish

### Second Violation (3 oy ichida)
- **Extended Suspension** - 1-4 hafta
- Qayta topshirish yoki o'qitish program

### Third Violation (6 oy ichida)
- **Permanent Ban** - Komunitydan chiqarilish
- Barcha accounts va access shut down

### Severe Violations
- **Immediate Permanent Ban**
  - Shiddatli tahdid
  - Jinsiy harassment
  - Diskriminatsiya
  - Doxxing

## 😊 Create Positive Community

### Bugun Qanday Qilish Mumkin

✅ **Assosiativ Xatti-Harakat**
```
// Yangi a'zosiga salamatsiz deyin
"Abdora AI komunityga xush kelibsiz! Agar savol bo'lsa, shoshilmang!"

// Miqdori feedback bering
"Bu feature fikri yaxshi, chunki... Buni qanday yaxshilash mumkin..."

// Xatolarni xushmuammona hal qiling
"Bu muammo xaqida o'ylashgandek, buni shunday hal qilish mumkin..."
```

❌ **Noto'g'ri Xatti-Harakat**
```
// Judges yoki critical bo'lma
"Bu kod juda yomon yozilgan!"

// Ad hominems qilma
"Siz ancha bilimsiz, bunday turli kod yozolmaysiz"

// Off-topic argumentlar
"Bu issue bilan bog'liqsiz, lekin siyosat haqida..."
```
